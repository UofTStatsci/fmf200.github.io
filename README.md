# FMF200 Website

Static website template for **The Future of Mathematical Finance: Celebrating U of T at 200**, hosted by the University of Toronto Department of Statistical Sciences.

## Publishing
GitHub Pages should be set to **Deploy from a branch** → `main` → `/ (root)`.

Upload the *contents* of this package to the root of the repository. No Jekyll, Ruby, npm, or build step is required.

## Main files
- `index.html` — homepage
- `about.html` — conference overview
- `program.html` — schedule
- `speakers.html` — speakers
- `registration.html` — registration
- `travel.html` — venue/travel
- `contact.html` — contact
- `assets/css/main.css` — all visual styling
- `assets/js/main.js` — mobile menu + automatic active navigation state

## Images
Place real images in:
- `assets/images/hero/`
- `assets/images/speakers/`
- `assets/images/venue/`
- `assets/images/branding/`

Placeholder image panels are currently built into the HTML so the template works without image files.

## Placeholders
Search the HTML files for square brackets such as `[DATE]`, `[XX]`, and `[Add ...]` to find content that still needs confirmed conference information.
