# FMF200

Website for **The Future of Mathematical Finance: Celebrating U of T at 200**, hosted by the University of Toronto Department of Statistical Sciences.

## Website

Public website: https://fmf200.statistics.utoronto.ca/

GitHub Pages: https://uoftstatsci.github.io/fmf200.github.io/

## Site Structure

The website is a static site built with HTML, CSS and JavaScript.

- `index.html` — Homepage
- `about.html` — About the conference
- `program.html` — Conference program
- `speakers.html` — Speakers
- `registration.html` — Registration
- `travel.html` — Travel and venue information
- `contact.html` — Contact information
- `assets/css/main.css` — Site styles
- `assets/js/main.js` — Site JavaScript
- `assets/images/` — Website images

## Publishing

The site is hosted using GitHub Pages and published directly from the `main` branch.

GitHub Pages settings:

- Source: Deploy from a branch
- Branch: `main`
- Folder: `/ (root)`

Changes committed to `main` are automatically published to the website.
